# 侧边导航配方

所有来源无默认。按 `navigation-selection.md` 处理共同流程，实际取用前核验版本和许可；下述依赖线索来自研究快照。

## drawer

daisyUI Drawer 以 HTML / Tailwind 为基础；先查项目 Tailwind 与 daisyUI 版本兼容性，React/Vue 只表示可以适配结构，不代表已经提供独立验收模板。

选择常驻、mini 或覆盖布局，保留账号、分组、路由和权限。检查抽屉关闭后的焦点顺序、Escape、遮罩、焦点归还和内容滚动；不要把 CSS 隐藏当作已完成焦点管理。移动抽屉属于此来源适配，不进入当前移动底栏目录。

## aceternity-sidebar

只针对 Sidebar component，不自动取用同站 Pro Blocks。保留折叠／展开信息层次；Hover 展开必须提供键盘与触屏可用的触发方式，避免焦点仍在栏内时收起。

适配当前页、分组、账号和路由，不把演示 Logout 直接连到未经确认的业务操作。验证短屏滚动、底部账号可达、内容推挤、主题及减少动态；静态降级保持可操作宽度。

## staggered-menu

React / Vue 分版取用，研究中使用 GSAP。用于侧向覆盖式菜单，不宣称常驻侧栏。导航顺序、真实路由与项目权限优先。

实现打开／关闭状态、Escape、焦点进入与归还、背景不可交互及滚动恢复；路由成功后关闭。验证快速反复操作、长列表、卸载动画清理和 SSR。减少动态时去除错峰，仍显示菜单；不把此来源自动选成移动底部导航。

## dashboard-sidebar

shadcn/studio 是区块集合。选型可以推荐该集合；实施必须先确定具体区块 ID、可访问源码、版本和适用授权。未确定时停在区块选择，不生成声称取自该来源的代码。

检查区块真正提供的折叠、子菜单、账号与工作区功能，去除行业 Demo 数据和无关 CTA，保留业务入口。验证布局宽度、当前页、键盘、移动抽屉和主题；不因为名称含 shadcn 就按 shadcn/ui 的许可或 API 处理。

## untitled-sidebar

当前仅确认 Figma 视觉参考，可讨论窄栏／双层导航的信息结构。`supportedStacks: []` 表示没有已核验的工程实现，不代表不允许选作设计参考。

用户要求实现时先明确采用已授权 React 来源还是按参考建立项目原创实现；核验具体素材、代码、版本与权限。不从预览图声称已有源码、免费许可或跨栈模板。验收以实际生成的导航行为为准。
