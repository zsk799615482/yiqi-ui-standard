# 悬浮导航配方

本文件是原创集成指导；事实来自 2026-10-09 的研究快照，实际取用按 `navigation-selection.md` 复核。所有条目无默认，不附带上游源码。React/Next 与 Vue/Nuxt 分别处理路由、生命周期及 SSR；没有 Vanilla 等价模板时不静默移植。

## pill-nav

适合带品牌入口、少量文字链接的悬浮头部。按栈选 React Bits 或 Vue Bits，不把两个版本叠装。研究中两版均有 GSAP 线索，React 版还有 react-router-dom；Next 项目需要明确路由适配。

把链接绑定项目导航数据，保留品牌资产、键盘焦点与当前页状态。容器宽度、Logo 是否显示、菜单数量遵循页面需求，不继承 17 Top-dock 全宽下拉契约。检查窄宽度、长文字、子菜单需求及减少动态。退化时保留链接与当前页，不隐藏内容等待动画。

## morphic-navbar

适合以选中胶囊表现当前位置的紧凑导航。研究来源含 Next Link；React 非 Next 项目先处理链接适配。悬浮定位、遮挡和滚动策略须由项目定义，不能凭名称假定已实现。

使用项目色彩与字体；验证切路由后选中态、前进后退、键盘和窄宽度。不能把纯 CSS 过渡称作已实现弹簧。无动效时保留明确选中背景。

## dock

React Bits、Vue Bits、nxui 按来源 ID 独立取用。研究中 React Dock 与 Vue Dock 的实现不同；Vue Bits / nxui 存在 motion-v 线索，nxui 还有 VueUse；不得为 React 版猜测安装相同依赖。

明确每个项目是跳转还是操作：跳转用链接，动作用按钮。提供可访问名称、焦点反馈、当前页及无需 Hover 的标签策略。位置和纵横排列只采用所选版本确实支持的能力。

检查放大后边缘裁切、点击目标稳定、键盘顺序、粗指针与减少动态。触屏不能依赖指针邻近动画；退化为稳定排列的图标与文本。完整多层后台导航不应被只有图标的 Dock 无说明替换。

## dynamic-island

nxui Dynamic Island Header 作为滚动变形／章节进度来源。先确认真正滚动容器、章节目标和布局偏移，再映射当前章节与滚动状态；不要默认把章节定位当作路由主导航。

研究依赖线索为 motion-v / VueUse。验证展开、滚动恢复、焦点保持、路由卸载清理和减少动态。导航正在操作时不应消失；静态降级保留章节入口。

## gooey-nav

React / Vue Bits Gooey Nav 属于选中态创意动效，不是光学液态玻璃容器。先保留真实链接与路由选中，再加视觉效果；不凭动效外观增加玻璃依赖。

控制粒子／溢出区域避免遮挡其他按钮，检查连续切换、路由更新、无 Hover、主题对比及减少动态。回退为稳定的选中样式，不损失导航能力。
