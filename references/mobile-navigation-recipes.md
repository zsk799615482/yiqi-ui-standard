# 移动底部导航配方

## konsta-tabbar

当前范围仅为 iOS 26 风格的底部标签栏。Konsta UI React / Vue 是两条可选择来源，均无默认；按项目栈选择，Vanilla 项目没有已核验的对应模板，需另提适配方案。

参考当前官方 Tabbar 与 ToolbarPane 的组合，不保证 Web 能复制系统原生光学效果。实际取用前锁定包版本，核验 iOS 主题、所需上下文、样式配置与容器 API；不要只把示例 JSX/SFC 放入项目而漏掉主题设置。

1. 使用真实主导航数据绑定路由、标签、权限与当前项，桌面和移动可共享数据但不共用布局；不添加无业务依据的搜索或播放器。
2. 以用户指定的 iOS 26 方向处理悬浮圆角、图标和短标签、材质及选中反馈；映射项目深浅色。先评估来源自带玻璃，避免叠加第二套滤镜。
3. 明确 safe-area、viewport 配置、底部内容留白和软键盘策略；固定栏不能遮挡最后一项内容或输入操作。
4. 滚动收缩、弹簧参数和菜单项数量由项目决定，不因“iOS 26”自动开启；减少动态时保持稳定选中态，材质退化时保留可读背景。
5. 验证真机或可用移动浏览器的触摸、横竖屏、长标签、安全区、键盘、前进后退、主题与 SSR。未实测设备明确列为未验证。

只实施请求的移动范围，不替换桌面导航或把抽屉、Bubble Menu、Staggered Menu 加入底栏候选。没有合适取用条件时说明缺口，不自动改用 daisyUI、MUI 等此前未确认来源。
