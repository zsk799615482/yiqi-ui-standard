# 17 Top-dock Implementation Plan

> **For agentic workers:** 使用独立适配器任务并行实现，保留现有改动；任务完成后由主代理统一审查。

**Goal:** 为现有 Skill 提供三栈全宽玻璃顶部导航模板。

**Architecture:** 共用 CSS、数据结构和弹簧适配器；各栈原语负责菜单语义；Full 材质由业务项目注入。
